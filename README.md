# Firefox Downloads for DynamicLake

**Firefox Downloads for DynamicLake** brings your Firefox downloads directly to the macOS DynamicLake, giving you a compact, glanceable view of active downloads without needing a browser extension.

Track download progress, speed, time remaining, downloaded amount, and file type directly from the notch. Important events such as completed, paused, stalled, failed, canceled, and blocked downloads are surfaced through DynamicLake's Sneak Peek, while supported browser actions let you stop, resume, or retry downloads without opening Firefox's Downloads panel.

The plugin is designed to work naturally alongside DynamicLake's other activities, supporting both the Main Activity and Extra Live Activity while handling multiple simultaneous downloads, sleep/wake, browser closure, and Away mode.

### Highlights

- Live download progress and details
- Sneak Peek notifications for important download events
- Stop, Resume, and Retry through Firefox's UI
- Open completed files with their default macOS application
- File-type identification
- Multiple simultaneous downloads with Main/Extra Activity support
- Sleep/wake and browser close/reopen handling
- Away mode with queued Sneak Peeks
- Safety-focused browser UI automation with exact download verification
- Compatible with Firefox and supported forks, including LibreWolf, Waterfox, Pale Moon, and Tor Browser
- No browser extension required

The plugin reads Firefox's local download state and uses browser UI automation only when an action needs to be performed, leaving Firefox in control of the actual downloads.
